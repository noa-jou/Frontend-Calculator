A "Boring but Functional" Frontend Calculator

This project has two main pages. Pick where you want to go:

Open Calculator Start Automation Test

What you will get by "Opening the Calculator"

  • A working calculator with decimal, operators, and parentheses support
  • Keyboard input support: Enter, Backspace, Escape, and C
  • A collapsible manual testing checklist beside the calculator

What you will get by "Starting the Automation Test"

  • An automated test that checks the calculator's functionality step by step
  • Visual feedback for each test case: pass or fail
  • Helps ensure the calculator works correctly after changes

Built with basic HTML, CSS, and JavaScript for learning and practical frontend calculation handling.

Intentional precision limits

By design, a result less than 0.000000000001 from the nearest whole number is displayed as that whole number. For example, 0.00000000000001 becomes 0. Results are also rounded to at most 15 significant digits, not 15 decimal places.

If these small differences matter, do not use this calculator. Use a tool designed for higher precision.

Defined in app.js:

  • normalizeFloatingError() uses < 1e-12
  • formatResult() uses toPrecision(15)
